## System Prompt

```
You are a senior UX designer and design systems architect.
Your job is to read a Definition Report and produce a complete Design Brief
that a developer can use to build in Bolt / Lovable / v0.dev immediately,
and a human designer can use to create high-fidelity mockups.

Rules:
- Read the HANDOFF section in the Definition Report first.
- Design for the primary persona ONLY at this stage.
- Every screen must map to a P0 user story from the Definition Report.
- Output ONLY in Markdown. No prose outside the defined sections.
- Be specific with layout, not vague — "left sidebar with nav" not "navigation component".
- Design decisions must reference a user need, not aesthetics.
- Language: ภาษาไทย (ยกเว้น technical/design terms)
```

### Screen: Pricing Page (Public)
**Maps to:** ผู้เยี่ยมชมต้องการเปรียบเทียบ plan ก่อนสมัคร
**Persona goal:** เข้าใจความแตกต่างระหว่าง tier และตัดสินใจ plan ที่เหมาะสม

#### Layout
```
┌──────────────────────────────────────────────┐
│  [Hero: headline + subtext]                  │
├──────────────────────────────────────────────┤
│  [Toggle: รายเดือน / รายปี (-20%)]           │
├──────────┬──────────────┬────────────────────┤
│  Free    │   Starter    │      Pro           │
│  ฿0      │   ฿XXX/mo    │    ฿XXX/mo         │
│  [CTA]   │   [CTA]      │   [CTA] ← highlight│
├──────────┴──────────────┴────────────────────┤
│  [Feature comparison table]                  │
│  [FAQ accordion]                             │
└──────────────────────────────────────────────┘
```

#### Components
| Section | Component | หมายเหตุ |
|---------|-----------|---------|
| Toggle | Billing period switch | เปลี่ยนราคาทุก card พร้อมกัน |
| Tier card | Price + features list + CTA button | Pro card มี border highlight |
| Feature table | Checkmark / X ต่อ feature ต่อ tier | copy จาก Feature Matrix ใน Step 02 |
| CTA | "เริ่มใช้งานฟรี" / "สมัคร [Plan]" | Free → signup, Paid → checkout |

#### Key Interactions
| Trigger | Action | Feedback |
|---------|--------|---------|
| Toggle billing period | อัปเดตราคาทุก card | animation slide ราคา |
| คลิก CTA paid plan | redirect → Stripe Checkout | loading state บน button |
| คลิก CTA free plan | redirect → signup page | — |

#### Edge Cases
- **Current plan:** ถ้า user login อยู่แล้ว — highlight plan ปัจจุบัน, เปลี่ยน CTA เป็น "Current Plan"
- **Downgrade:** ถ้า plan ปัจจุบันสูงกว่า — แสดง warning modal ก่อน confirm

### Screen: Settings / Billing
**Maps to:** User ต้องการดู plan ปัจจุบัน, upgrade, หรือ cancel
**Persona goal:** จัดการ subscription โดยไม่ต้องติดต่อ support

#### Layout
```
┌──────────────────────────────────────────────┐
│  Current Plan: Pro  [Upgrade / Change Plan]  │
│  Next billing: 1 ม.ค. 2026  ฿XXX             │
├──────────────────────────────────────────────┤
│  Usage this month                            │
│  AI Requests  ████████░░  80/100             │
│  Storage      ███░░░░░░░  300MB / 1GB        │
├──────────────────────────────────────────────┤
│  Payment method  [Visa ****4242]  [เปลี่ยน]  │
│  Billing history  [ดู invoices]              │
├──────────────────────────────────────────────┤
│  [ยกเลิก subscription]  ← destructive, small │
└──────────────────────────────────────────────┘
```

#### Key Interactions
| Trigger | Action | Feedback |
|---------|--------|---------|
| คลิก Upgrade | redirect → Pricing Page | — |
| คลิก เปลี่ยน payment | Stripe Customer Portal | new tab |
| Usage bar ≥ 80% | แสดง warning banner | "คุณใช้ไปแล้ว 80% — upgrade เพื่อใช้ไม่จำกัด" |
| คลิก ยกเลิก | confirmation modal | "plan จะหมดอายุวันที่ XX" |

### Component: Paywall / Upgrade Prompt
